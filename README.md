# Бот-визитка Дины Ахмедовой

## Файлы
- bot.py — Telegram бот (визитка, отзывы, окошки, запись, ИИ-ассистент)
- vk_bot.py — простой ВК-бот с ИИ-ответами (для проекта #4)
- main.py — запускает оба бота вместе
- slots.json — список свободных окошек (редактируется через /okna в боте)
- images/ — сюда положить welcome.jpg, review1.jpg, review2.jpg, review3.jpg
